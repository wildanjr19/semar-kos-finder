## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Chip gaps, icon padding |
| sm | 8px | Button/internal padding, card gaps |
| md | 16px | Sidebar padding, section margins |
| lg | 24px | Layout gaps, popup padding |
| xl | 32px | Major section breaks |
| 2xl | 48px | Map fitBounds padding |
| 3xl | 64px | Page-level spacing |

Exceptions:
- **38px** — map marker diameter (existing imperative marker size, not a touch target)
- **44px** — FAB toggle button (minimum accessible touch target, per D-03)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 13px | 400 | 1.5 |
| Label | 11px | 700 | 1.3 |
| Heading | 22px | 700 | 1.15 |

**Normalization note:** Existing inline styles use 600–900 arbitrarily. CSS modules normalize to exactly two weights (400, 700). Uppercase labels use `letter-spacing: 0.12em`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` / `#f8fafc` | Page background, map underlay, popup base |
| Secondary (30%) | `#f0fdfa` | Sidebar gradient tint, card backgrounds, hover states |
| Accent (10%) | `#0f766e` | Primary actions, active route line, category labels, popup border |
| Destructive | `#be123c` | Error states, failed route calculation, validation errors |

Accent reserved for:
- Primary action buttons (e.g. "Tampilkan rute")
- Category labels and uppercase section headings
- Active route polyline stroke
- Selected/expanded state indicators
- Popup card border tint (`rgba(15, 118, 110, 0.18)`)

**Semantic palette (existing, preserve):**
- Putri: `#fdf2f8` bg / `#ec4899` border / `#9d174d` text
- Putra: `#eff6ff` bg / `#3b82f6` border / `#1d4ed8` text
- Campuran: `#f0fdf4` bg / `#22c55e` border / `#166534` text

## Phase-Specific Contracts

### Layout (from `01-CONTEXT.md` D-01 … D-05)

- **Sidebar:** Fixed width `min(356px, calc(100vw - 32px))` on desktop; full-width on viewports < 760px.
- **FAB toggle:** Floating action button over map toggles sidebar open/closed on desktop.
- **Preview list:** Collapsible, starts collapsed, expands on click (max 5 items).
- **Stats bar:** 4-column grid (Total / Putri / Putra / Campur) remains in sidebar during Phase 1; becomes secondary/moves to filter chips in Phase 2.
- **Scroll:** Sidebar scrolls independently (`overflow-y: auto`), map container is fixed (`100dvh`).

### Component Inventory (from `01-CONTEXT.md` D-12)

Extracted components with CSS modules in `frontend/app/prototype/clean-map/components/`:

| Component | Module | Purpose |
|-----------|--------|---------|

### Glassmorphism Spec (preserve from existing prototype)

- Sidebar background: `linear-gradient(160deg, rgba(255,255,255,0.94) 0%, rgba(240,253,250,0.94) 62%, rgba(248,250,252,0.94) 100%)`
- Backdrop filter: `blur(14px)`
- Border: `1px solid rgba(15, 118, 110, 0.18)`
- Shadow: `0 24px 54px rgba(15, 23, 42, 0.18)`
- Border radius: `22px`
