## UI-SPEC contracts (MUST follow exactly)

### Spacing Scale
| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Chip gaps, icon padding |
| sm | 8px | Button/internal padding, card gaps |
| md | 16px | Sidebar padding, section margins |
| lg | 24px | Layout gaps, popup padding |
| xl | 32px | Major section breaks |
| 2xl | 48px | Map fitBounds padding |
| 3xl | 64px | Page-level spacing |

### Typography
| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 13px | 400 | 1.5 |
| Label | 11px | 700 | 1.3 |
| Heading | 22px | 700 | 1.15 |
| Display | 18px | 700 | 1.3 |

Uppercase labels: `letter-spacing: 0.12em`
Normalize to exactly two weights: 400, 700.

### Color
| Role | Value | Usage |
|------|-------|-------|
| Dominant | `#ffffff` / `#f8fafc` | Page background, map underlay, popup base |
| Secondary | `#f0fdfa` | Sidebar gradient tint, card backgrounds, hover states |
| Accent | `#0f766e` | Primary actions, active route line, category labels, popup border |
| Destructive | `#be123c` | Error states |

Semantic palette (preserve):
- Putri: `#fdf2f8` bg / `#ec4899` border / `#9d174d` text
- Putra: `#eff6ff` bg / `#3b82f6` border / `#1d4ed8` text
- Campuran: `#f0fdf4` bg / `#22c55e` border / `#166534` text

### Border Radius Tokens
| Token | Value | Usage |
|-------|-------|-------|
| pill | 999px | Chips, badges, FAB, markers |
| card | 14px | Stat cards, preview items |
| panel | 18px | Popup container |
| sidebar | 22px | Sidebar container |
| input | 12px | Selects, text inputs |
| button | 10px | Action buttons |

### Glassmorphism Spec
- Sidebar background: `linear-gradient(160deg, rgba(255,255,255,0.94) 0%, rgba(240,253,250,0.94) 62%, rgba(248,250,252,0.94) 100%)`
- Backdrop filter: `blur(14px)`
- Border: `1px solid rgba(15, 118, 110, 0.18)`
- Shadow: `0 24px 54px rgba(15, 23, 42, 0.18)`
- Border radius: `22px`

### Layout
- Sidebar width: `min(356px, calc(100vw - 32px))` on desktop; full-width on viewports < 760px
- FAB toggle: 44px minimum touch target, floating over map
- Preview list: collapsible, starts collapsed, expands on click, max 5 items
- Scroll: Sidebar scrolls independently (`overflow-y: auto`), map container is fixed (`100dvh`)
